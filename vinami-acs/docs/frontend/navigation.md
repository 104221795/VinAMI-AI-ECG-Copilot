# Navigation

Public product routes in F0 are:

- `/command-center`
- `/cases/[caseId]`
- `/cases/[caseId]/timeline`
- `/cases/[caseId]/audit`
- `/system-health`

The primary sidebar contains Command Center and System Health. Once a case is selected, Overview, Timeline and Audit appear as case navigation. Filters and selected case are URL-addressable. There are no ECG, troponin, pathway, triage, task or alert routes because those capabilities are not part of verified R1.

The shell includes a skip link, semantic landmarks, environment/research status, verified actor, connectivity and refresh. Narrow layouts preserve the same navigation without inventing a separate clinical hierarchy.
