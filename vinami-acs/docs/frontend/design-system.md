# Clinical Design System

The default workspace is a calm, high-contrast light theme. Semantic CSS tokens define surfaces, text, borders, focus, interaction, priority, warning, critical, stale and offline states. Status is always expressed with text in addition to color.

Reusable primitives include AppShell, ClinicalSidebar, CommandHeader, PageHeader, Breadcrumbs, EnvironmentBadge, ResearchUseBadge, IdentityBadge, ConnectivityIndicator, StatusBadge, PriorityBadge, MetricTile, ClinicalCard, DataTable, FilterBar, SearchField, Pagination, Timestamp, ElapsedTime, EmptyState, LoadingSkeleton, ErrorState, OfflineState, StaleDataBanner, TechnicalDetailsDisclosure, TimelineItem, AuditTable, ConfirmationDialog and SafeActionButton.

Storybook documents normal, loading, empty, error, stale, critical, narrow, long-text and unknown-value states. Focus indicators, reduced-motion behavior, tabular values and responsive table wrapping are defined in `apps/web/app/globals.css`. No gradient, glow, glass effect, AI motif or marketing hero is used.
